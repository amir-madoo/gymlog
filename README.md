# GymLog — Dark Mode 12-Week Aesthetic Tracker

Minimalistic dark-mode workout, posture/core, cardio, steps, and Sunday body-weight tracker designed for GitHub Pages and iPhone Safari Home Screen.

## Files Included
- `index.html` — Main app shell & iOS standalone Home Screen tags
- `styles.css` — Minimalistic dark-mode-only stylesheet
- `program.js` — 6-day Aesthetic V-Taper + Anti-Slouch programme & 12-week scaling rules
- `app.js` — LocalStorage tracker, strict day-locking, rest timer, last-session history & JSON backup
- `manifest.json` — Standalone web app manifest
- `apple-touch-icon.png` & `icon-512.png` — Crisp dark Home Screen app icons

## Deploy on GitHub Pages
1. Unzip this folder on your computer.
2. Create a new public GitHub repository (e.g. `gym-log`).
3. Click **Add file → Upload files**, drag **all files from inside the unzipped folder** into the root of the repo, and click **Commit changes**.
4. Open **Settings → Pages**, set **Source** to `Deploy from a branch`, select `main` and `/ (root)`, then click **Save**.
5. Wait ~1 minute, open your `https://<username>.github.io/gym-log/` URL in **Safari on iPhone**, tap **Share → Add to Home Screen → Add**.
