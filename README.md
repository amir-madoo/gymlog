
## Deploy on GitHub Pages
1. Unzip this folder on your computer.
2. Create a new public GitHub repository (e.g. `gym-log`).
3. Click **Add file → Upload files**, drag **all files from inside the unzipped folder** into the root of the repo, and click **Commit changes**.
4. Open **Settings → Pages**, set **Source** to `Deploy from a branch`, select `main` and `/ (root)`, then click **Save**.
5. Wait ~1 minute, open your `https://<username>.github.io/gym-log/` URL in **Safari on iPhone**, tap **Share → Add to Home Screen → Add**.
